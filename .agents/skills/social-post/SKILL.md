# LazyNoMan Social Post Skill

Converts novel review content into platform-optimized social media posts for **Facebook** and **X (Twitter)**.

---

## Platform Rules

### Facebook (Long Form)
- **Tone**: Conversational, punchy, personality-driven. Reads like a friend recommending something.
- **Length**: 4–8 sentences. No hard limit. Long is fine and preferred.
- **Structure**:
  1. **Hook line** — One punchy contrast or concept that makes someone stop scrolling. Usually a "everyone else does X — this guy does Y" or a core concept twist.
  2. **Core loop / concept** — Explain the cheat/system/premise in plain terms. Keep it exciting.
  3. **Best part** — What chapters or arcs shine? Be specific (e.g. "first 300 chapters").
  4. **Honest flaws** — Name them directly. Don't sugarcoat. One or two sentences.
  5. **Who it's for** — End with a clear "if you want X, this is for you" line.
  6. **Score** — Always include `My score: X/10`
  7. **Full Review link** — Always include the full URL
  8. **Hashtags** — Always end with: `#webnovel #cultivation #novelreview #lazynoman`
- **Do NOT** shorten or compress. FB rewards engagement. Let it breathe.

#### Facebook Example Pattern:
```
[Hook — contrast or premise twist]

[Explain the core loop/cheat in 1-2 sentences]

[What's great — be specific about chapters/arcs]

[Flaws — honest, direct]

[Who it's for — closing pitch]

My score: X/10

Full Review: [URL]

#webnovel #cultivation #novelreview #lazynoman
```

---

### X / Twitter (Short Form)
- **Hard limit**: 280 characters total
- **Link always counts as 23 characters** (X's t.co shortener — fixed regardless of URL length)
- **Hashtags to use**: `#webnovel #cultivation #lazynoman` (3 only — saves space)
- **Structure** (fit within ~200 chars of actual text + 23 link + ~40 hashtags):
  1. One-line hook or core premise (punchy)
  2. Core loop explained in one sentence
  3. Highlight (best chapters or standout quality)
  4. Score
  5. Raw URL (no emoji before it)
  6. Hashtags
- **Do NOT** use emojis before the link — wastes characters
- **Do NOT** use full sentences when fragments work
- **Trim aggressively**: Remove filler words, articles (a/the), and names when context is clear

#### X Example Pattern:
```
[One-line hook]

[Core loop in one sentence]

[Best part — X chapters = Y quality. Flaw if space allows.]

[Score]

[raw URL no emoji]

#webnovel #cultivation #lazynoman
```

#### Character Budget:
| Element | Approx chars |
|---|---|
| Hook line | ~60 |
| Core loop | ~60 |
| Highlight + score | ~40 |
| URL (always 23) | 23 |
| Hashtags | ~40 |
| **Total** | **~223** ✅ |

## Writing Style Rules (Both Platforms)

- **Voice**: Direct, no fluff, slightly sarcastic/casual. Like a reader talking to a reader.
- **Score format**: Always `X/10` — never "I give it" or "rating:"
- **Flaws**: Always mention at least one. Never all praise.
- **Cheat/System**: Explain it simply. Readers may not know the novel.
- **No spoilers**: Keep plot vague. Focus on concept and feel.
- **"Chill" reads**: Use phrases like "zero-stress", "junk food read", "OP MC", "carried by his cheat"
- **High-stakes reads**: Use phrases like "stakes are real", "dread builds", "grounded MC"

---

## Input → Output Process

1. Read the provided review text or URL content
2. Extract: premise/cheat, best chapters, flaws, score, review URL
3. Write FB post first (long form)
4. Write X post second (compressed, count characters mentally)
5. Present both clearly labeled

---

## Common Mistakes to Avoid

- ❌ Making X post too long (over 280 chars)
- ❌ Forgetting the link on either platform
- ❌ Using wrong hashtags (FB uses 4, X uses 3)
- ❌ Making FB post too short / robbing it of personality
- ❌ Putting emoji before URL on X (wastes chars)
- ❌ Forgetting score on either platform
