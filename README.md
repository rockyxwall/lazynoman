# LazyNoman Blog

A personal blog project for sharing thoughts, projects, and ideas.

## 🚀 Project Structure

Inside of your project, you'll see the following folders and files:

```text
├── public/
├── src/
│   ├── components/
│   ├── content/
│   ├── layouts/
│   └── pages/
├── astro.config.mjs
├── README.md
├── package.json
└── tsconfig.json
```

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `bun install`             | Installs dependencies                            |
| `bun dev`             | Starts local dev server                          |
| `bun build`           | Build your production site                       |
| `bun preview`         | Preview your build locally                       |
